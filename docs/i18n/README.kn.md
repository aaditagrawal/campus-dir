# ಎಂಐಟಿ ಮಣಿಪಾಲ ಕ್ಯಾಂಪಸ್ ಡೈರೆಕ್ಟರಿ

ಎಂಐಟಿ ಮಣಿಪಾಲ ವಿದ್ಯಾರ್ಥಿಗಳಿಗಾಗಿ ಕ್ಯಾಂಪಸ್ ಡೈರೆಕ್ಟರಿ. ಇಲ್ಲಿ ಉಪಾಹಾರಗೃಹಗಳು, ವಸತಿ ನಿಲಯಗಳು, ಪ್ರಯಾಣ, ಸೇವೆಗಳು, ಶೈಕ್ಷಣಿಕ ಸಂಪನ್ಮೂಲಗಳು, ಕುಂದುಕೊರತೆ ಸಂಪರ್ಕಗಳು ಮತ್ತು ತುರ್ತು ಸಂಖ್ಯೆಗಳನ್ನು ಹುಡುಕಬಹುದು.

## ಸ್ಥಳೀಯವಾಗಿ ಚಲಾಯಿಸಿ

```bash
git clone https://github.com/aaditagrawal/campus-dir.git
cd campus-dir
bun install
bun dev
```

`http://localhost:3000` ತೆರೆಯಿರಿ. ಡೇಟಾ ತಿದ್ದುಪಡಿಗಳಿಗೆ `src/data/*.json` ಸಂಪಾದಿಸಿ; ವಿವರಗಳಿಗೆ [ಕೊಡುಗೆ ಮಾರ್ಗದರ್ಶಿ](CONTRIBUTING.kn.md) ನೋಡಿ.
