# एमआईटी मणिपाल निर्देशिका

एमआईटी मणिपाल के छात्रों के लिए कैंपस निर्देशिका। इसमें रेस्तरां, छात्रावास, यात्रा, सेवाएँ, शैक्षणिक संसाधन, शिकायत संपर्क और आपातकालीन नंबर मिलते हैं।

## इसमें क्या है

- रेस्तरां के फोन नंबर, शुल्क, पते और खुलने की स्थिति।
- छात्रावास ब्लॉक, वार्डन, रिसेप्शन और संपर्क विवरण।
- ऑटो, कैब और हवाई अड्डे की यात्रा संबंधी जानकारी।
- शैक्षणिक पोर्टल, कैंपस जीवन, सेवाएँ और आधिकारिक शिकायत संपर्क।
- सभी निर्देशिका सामग्री में खोज, पसंदीदा संपर्क और vCard डाउनलोड।

## स्थानीय रूप से चलाएँ

```bash
git clone https://github.com/aaditagrawal/campus-dir.git
cd campus-dir
bun install
bun dev
```

फिर `http://localhost:3000` खोलें।

## योगदान

संपर्क या संसाधन सुधारने के लिए `src/data/*.json` में बदलाव करें। कोड परिवर्तन के लिए अलग फीचर शाखा बनाकर जाँच के बाद पुल अनुरोध खोलें। विस्तृत निर्देशों के लिए [हिन्दी योगदान मार्गदर्शिका](CONTRIBUTING.hi.md) देखें।

## तकनीक

यह परियोजना Next.js 16, React 19, TypeScript, StyleX, Radix UI और MiniSearch का उपयोग करती है।
