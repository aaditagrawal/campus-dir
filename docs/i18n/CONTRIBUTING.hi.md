# एमआईटी मणिपाल निर्देशिका में योगदान

योगदान के लिए धन्यवाद। कैंपस की जानकारी उपयोगी, सत्यापित और स्पष्ट रखें।

## त्वरित शुरुआत

1. रिपॉज़िटरी को फोर्क करें और फीचर शाखा बनाएँ।
2. डेटा परिवर्तन के लिए `src/data/` की उपयुक्त JSON फ़ाइल संपादित करें।
3. कोड परिवर्तन के लिए `bun install` और `bun dev` चलाएँ।
4. जाँच पूरी करके केंद्रित पुल अनुरोध भेजें।

## डेटा नियम

- फोन नंबर, घंटे, पते और लिंक को प्रकाशित करने से पहले सत्यापित करें।
- केवल आधिकारिक या व्यवसायिक संपर्क जोड़ें; व्यक्तिगत नंबर न जोड़ें।
- अज्ञात विवरण के लिए `-` लिखें और मौजूदा JSON संरचना बनाए रखें।
- बंद सेवा को हटाएँ या उसकी स्थिति स्पष्ट रूप से अपडेट करें।

## कोड नियम

- TypeScript में स्पष्ट प्रकार लिखें और `any` से बचें।
- StyleX और `src/styles/` के साझा टोकन उपयोग करें।
- सुलभ लेबल, अर्थपूर्ण HTML और मोबाइल-प्रथम लेआउट रखें।
- फ़ाइल नाम kebab-case और React घटक PascalCase में रखें।

## जाँच

पुल अनुरोध से पहले चलाएँ:

```bash
bun run lint
bun run check:styles
bun run typecheck
bun run build
```

सभी पृष्ठ, खोज, थीम, मोबाइल नेविगेशन, संपर्क लिंक और बदली हुई सुविधा को हाथ से भी जाँचें। AI-सहायता से बने योगदान में उपयोग किया गया प्रॉम्प्ट पुल अनुरोध विवरण में शामिल करें।
