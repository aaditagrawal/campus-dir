# ಎಂಐಟಿ ಮಣಿಪಾಲ ಡೈರೆಕ್ಟರಿಗೆ ಕೊಡುಗೆ

ಮಾಹಿತಿಯನ್ನು ನಿಖರ, ಪರಿಶೀಲಿತ ಮತ್ತು ಸ್ಪಷ್ಟವಾಗಿಡಲು ಸಹಾಯ ಮಾಡಿದಕ್ಕಾಗಿ ಧನ್ಯವಾದಗಳು.

1. ರೆಪೊಸಿಟರಿಯನ್ನು ಫೋರ್ಕ್ ಮಾಡಿ ಮತ್ತು ವೈಶಿಷ್ಟ್ಯ ಶಾಖೆ ರಚಿಸಿ.
2. ಡೇಟಾ ಬದಲಾವಣೆಗಳಿಗೆ `src/data/` ನ ಸೂಕ್ತ JSON ಫೈಲ್ ಸಂಪಾದಿಸಿ.
3. ಕೋಡ್ ಬದಲಾವಣೆಗಳಿಗೆ `bun install` ಮತ್ತು `bun dev` ಚಲಾಯಿಸಿ.
4. PR ಮೊದಲು `bun run lint`, `bun run check:styles`, `bun run typecheck`, ಮತ್ತು `bun run build` ಚಲಾಯಿಸಿ.

ಅಧಿಕೃತ ಅಥವಾ ವ್ಯವಹಾರಿಕ ಸಂಪರ್ಕಗಳನ್ನು ಮಾತ್ರ ಸೇರಿಸಿ, ಪ್ರಕಟಿಸುವ ಮೊದಲು ಸಂಖ್ಯೆಗಳು ಮತ್ತು ಲಿಂಕ್‌ಗಳನ್ನು ಪರಿಶೀಲಿಸಿ, ಮತ್ತು StyleX/TypeScript ಯೋಜನಾ ನಿಯಮಗಳನ್ನು ಅನುಸರಿಸಿ.
